# RRG India — Institutional Capital Rotation Intelligence

Relative Rotation Graph system for NSE/NIFTY 50 with sector rotation engine.

## Architecture
- NSE Bhavcopy → parquet pipeline
- Relative Strength + Momentum engine  
- Sector + Stock leadership ranking
- RRG visualization (Plotly)
